# TAZEKA sürümleri

Bu depo yalnızca TAZEKA uygulamasının yayınlanmış sürümlerini (APK) ve
uygulamanın "Yeni sürüm var" denetiminde okuduğu `latest.json` dosyasını
barındırır. Uygulamanın kaynak kodu burada değildir.

- Son sürüm: [Releases](../../releases/latest)
- APK'lar aynı imza anahtarıyla imzalanır; Android yalnızca bu anahtarla
  imzalanmış sürümü mevcut uygulamanın üzerine kurar.
