# TAZEKA sürümleri

TAZEKA, ailelerin mutfaktaki ürünleri birlikte takip etmesi için TepeKod
tarafından geliştirilen bir Android uygulamasıdır.

- [Gizlilik politikası](gizlilik-politikasi.md)
- [Hesap ve veri silme](hesap-silme.md)
- İletişim: tepekod@gmail.com

Bu depo ayrıca uygulamanın yayınlanmış son sürümünü (APK) ve uygulamanın
"Yeni sürüm var" denetiminde okuduğu `latest.json` dosyasını barındırır.
Uygulamanın kaynak kodu burada değildir. APK'lar aynı imza anahtarıyla
imzalanır; Android yalnızca bu anahtarla imzalanmış sürümü mevcut uygulamanın
üzerine kurar.
